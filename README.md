# 🦉 English Quest

Interaktivní webová aplikace pro učení angličtiny – hravě, podle tvé úrovně a bez instalace.

**▶ Vyzkoušej online:** https://kali84-ai.github.io/cizi_jazyk/

## Co umí
- **Volba pokročilosti A1–C2** (podle Evropského referenčního rámce) – nebo **rozřazovací test**, který úroveň doporučí.
- **7 tréninkových režimů**
  - 🃏 **Kartičky** – otáčecí karty s výslovností a příkladovou větou
  - 🎯 **Kvíz** – překlad oběma směry
  - 🧩 **Doplň slovo** – slovo ve větě
  - 🎧 **Poslech** – slyšíš slovo a napíšeš ho (tolerance drobných překlepů)
  - 🧱 **Skládání vět** – poskládej větu ze slov
  - 🎙️ **Výslovnost** – rozpoznávání řeči (Chrome / Edge)
  - 🌀 **Mix výzva** – vše dohromady za dvojnásobné XP
- **Chytré opakování** (Leitnerův systém) – slova, která ti nejdou, uvidíš častěji.
- **Motivace** – XP, hráčské levely, denní cíl, série dní 🔥, combo, odznaky a konfety 🎉.
- Světlý / tmavý motiv, ovládání klávesnicí (1–4, Enter, mezerník), funguje i na mobilu.
- Pokrok se ukládá v prohlížeči (`localStorage`).

## Spuštění lokálně
Stačí otevřít `index.html` v prohlížeči. Žádné závislosti ani build.

## Technologie
HTML, CSS, čistý JavaScript, Web Speech API (syntéza i rozpoznávání řeči), Web Audio API.
